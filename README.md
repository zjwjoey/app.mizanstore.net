# Mizan APP 官方下载页

一个可直接部署的纯静态下载页面。

## 本地打开

直接双击 `index.html`，或使用任意静态文件服务器打开项目目录。

## 修改下载地址

编辑 `script.js` 顶部的 `DOWNLOAD_CONFIG`：

- `android`：Android 跳转地址
- `ios`：中国区 App Store 地址

## 替换 App 图标

替换 `assets/mizan-app.png` 即可。建议保留正方形 PNG/WebP 图片。

## 静态部署

将 `index.html`、`style.css`、`script.js` 和 `assets/` 一起上传到任意静态网站托管服务即可。
